# Desafio Educação Alagoas

Aplicação web para upload e análise de dados públicos de educação de municípios de Alagoas (2007–2025). Recebe um CSV em formato longo, processa e valida os dados no backend, e alimenta um dashboard com filtros, indicadores agregados e gráficos.

Este README será expandido ao longo do desenvolvimento com: como rodar o projeto do zero, variáveis de ambiente, e principalmente as decisões de tratamento dos dados (hierarquia de redes de ensino, agregação de percentuais, estratégia de reimportação, tratamento de valores ausentes).

## Estrutura

- `backend/` — API Node.js + Express + TypeScript + Prisma
- `frontend/` — React + TypeScript + Vite + Tailwind CSS
